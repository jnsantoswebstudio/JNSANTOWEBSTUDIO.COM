# JN Santos Web Studio

Portfólio estático preparado para GitHub Pages.

## Publicar
1. Envie todos os arquivos e a pasta `assets` para a raiz do repositório.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**.
4. Selecione a branch `main` e a pasta `/ (root)`.
5. Salve e aguarde o link do GitHub Pages ficar disponível.

Não há build, npm ou framework: o site funciona diretamente com `index.html`.
